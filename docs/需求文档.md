# 中国象棋棋谱编辑器（PRD）

## 文档信息
- 版本：V1.0（基于现有代码反推）
- 日期：2026-02-17
- 适用范围：本地浏览器单机使用的教学/棋谱研究工具
- 目标读者：产品、教练/研究用户、开发与测试

## 1. 背景与目标
中国象棋教学与棋谱研究需要一个轻量、离线、可快速记录与整理变着的工具。该产品以“棋谱编辑 + 片段化研究 + 复盘演示”为核心，提供可视化棋盘、标准走子、棋谱记录与标注能力，并支持导入/导出棋谱文件。

目标：
- 让教学者快速记录棋局并添加注释
- 支持“从此变着”生成片段，便于教学讲解
- 支持播放片段、语音朗读，提升演示效率
- 本地文件保存/打开，便于长期积累棋谱

## 2. 目标用户与使用场景
目标用户：
- 中国象棋教练/学员/爱好者（教学与复盘）

典型场景：
- 课堂上对弈并记录关键走法
- 保存多个棋局到一个棋谱书文件
- 对同一局面创建不同变着片段
- 播放片段并配合语音讲解

## 3. 产品范围（核心功能）
- 棋盘对弈与走子校验（基础规则）
- 棋谱记录与注释
- “从此变着”生成片段
- 片段集合视图与标记（分支点/下划线）
- 片段播放（含变速规则）与语音朗读
- 棋盘翻转与棋谱镜像
- 多棋局管理（新增/删除/恢复/改名/排序/切换）
- 文件管理（新建/打开/保存/另存为）
- 对弈时钟（包干制/加秒制/步时制）

## 4. 关键流程
1) 新建棋谱书 → 录入棋局 → 生成片段 → 保存
2) 打开棋谱书 → 选择棋局 → 片段播放 → 复制棋谱
3) 摆棋 → 开始对弈 → 注释关键着法 → 变着/镜像

## 5. 功能需求详述（含验收）

### 5.1 棋盘与走子
- 提供 9x10 中国象棋棋盘视图，棋子点击选择与落子。
- 基础走子规则校验：帅/将、士、相/象、车、马、炮、兵/卒。
- 结束条件：吃掉对方帅/将或时钟时间用尽即结束。

验收：
- 非法走法提示“走法不合法”。
- 同色棋子不可互吃。
- 吃掉对方帅/将时弹窗提示胜负并停止计时。

### 5.2 棋谱记录与注释
- 每步落子自动生成棋谱文本并记录到“当前线路”。
- 支持选中某步并添加/保存/清除注释。
- 当前线路可高亮当前步与被选中步。

验收：
- 落子后记录区出现“步号+走法”。
- 注释在记录区显示，且选中步时可查看/编辑。

### 5.3 片段与变着
- “从此变着”：将当前完整线路保存为片段，并基于所选步生成新线路。
- 自动在新线路对应步标记分支点（仅标记）。
- 片段集合视图可查看多个片段及其步法、注释。

验收：
- 生成片段后，片段集合中出现“棋局X（1-N着）”标题。
- 新线路步号从 1 重新编号。
- 分支点标记在当前线路中可见。

### 5.4 标记能力
- 当前线路：允许标记/修改/删除分支点（仅标记）。
- 片段集合：进入编辑模式后，可对某步添加/移除下划线标记。

验收：
- 当前线路仅允许一个分支点存在。
- 片段编辑模式下，下划线标记可切换并立即生效。

### 5.5 片段播放与语音
- 仅在“片段集合”模式下播放。
- 播放当前片段（当前实现为第一个片段）或播放全部片段。
- 片段 1：全程正常速度；片段 2+：分支点前快速、之后正常。
- 正常速度下支持语音朗读走法。

验收：
- 播放时当前步高亮，显示速度指示。
- 点击“停止播放”后恢复状态信息。
- 关闭语音开关后不再朗读。

### 5.6 棋盘翻转与棋谱镜像
- 棋盘翻转：仅影响显示朝向，不改变逻辑坐标。
- 棋谱镜像：仅在“当前棋局且仅一个片段”时可用，生成新棋局。

验收：
- 翻转后点击落子仍正确映射坐标。
- 镜像生成新棋局，名称为“镜像{原名}”。

### 5.7 多棋局管理
- 支持上一局/下一局切换；上移/下移排序；删除/恢复；更名。
- 下拉框显示棋局名、时间、片段数量。

验收：
- 删除后可从“恢复棋局”还原。
- 更名后下拉框立即更新。

### 5.8 文件管理
- 新建、打开、保存、另存为棋谱书（JSON）。
- 状态栏显示文件名与“已修改”提示。
- 优先使用 File System Access API；不支持时使用传统文件选择/下载。

验收：
- 保存后状态栏恢复为“未修改”。
- 打开文件后自动加载第一个棋局。

### 5.9 计时与规则
- 计时规则：包干制、加秒制、步时制。
- 支持开始、暂停/继续、重置。
- 每走一步自动切换计时方。

验收：
- 不同规则下，时钟显示与设置项正确切换。
- 超时触发胜负提示并停止计时。

## 6. 数据与文件格式（摘要）
棋谱书保存为 JSON，包含版本信息与棋局列表：
- 顶层：`version`、`created`、`modified`、`games[]`
- 每局：`id`、`name`、`timestamp`、`fragments[]`、`currentLine[]`、`comments`、`branchPoints`、`boardState`、`isFlipped`

说明：
- `fragments` 中包含 `moves[]`、`comments`、`branchPoints`、`underlineMarks`、`boardState` 等。
- 注释与标记均按“步号索引”存储。

## 7. 规则与约束
- 规则实现为“基础走子合法性”，不包含将军/将死/和棋/长将等完整规则判断。
- 终局判定为“吃将”或“时间到”。
- 仅本地单机使用，无账号、无网络同步。
- 文件管理依赖现代浏览器 API，低版本浏览器降级为传统文件方案。

## 8. 非功能性要求
- 启动即用，无需网络。
- 棋盘交互响应及时（落子、渲染、播放无明显卡顿）。
- 关键操作提供明确提示（弹窗/状态信息）。

## 9. 不在范围（当前实现未包含）
- 联网对弈、AI 引擎分析、棋局云同步
- 完整规则判定（将军、将死、和棋等）
- 多人协作/分享链接/账户体系
- 移动端专用适配与离线安装包

## 10. 风险与待确认
- 片段播放“当前片段”目前固定为第一个片段，是否应改为“当前选中片段”？
- 本地存储仅在启动时读取 `localStorage`，未看到写入逻辑，是否需要自动保存？
- 镜像功能仅支持“单片段棋局”，是否需要扩展到多片段？
- 分支点目前为单一标记，是否需要多分支点或真实分支树？
