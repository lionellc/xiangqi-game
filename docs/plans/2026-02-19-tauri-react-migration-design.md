# 中国象棋棋谱编辑器（Tauri + React + TS）改写设计

日期：2026-02-19

## 背景与目标
现有项目为浏览器版中国象棋棋谱编辑器，功能完整但为单页结构与单文件实现，维护成本高。目标是将其改写为 **Tauri v2 + React + TypeScript** 桌面端应用，并**一次性功能对齐现有全部功能**，同时为后续现代化视觉与可维护拆分打基础。

## 非目标
- 本阶段不追求重构为完全可插拔架构
- 不引入新的棋规/AI 对弈功能
- 不做大规模视觉重设计，仅保证与旧版一致可用

## 技术栈与目录策略
- 前端：React + TypeScript + Vite
- 桌面：Tauri v2
- 状态：Zustand
- 棋盘渲染：Konva / react-konva
- 文件：@tauri-apps/plugin-dialog + @tauri-apps/plugin-fs

目录建议：
- `src/components/`：UI 组件（BoardCanvas/ClockPanel/RecordPanel/ControlPanel/SetupPanel/StatusBar）
- `src/features/`：跨组件业务组合（可后续拆分）
- `src/store/`：Zustand 状态与动作（先集中，后拆 slice）
- `src/lib/`：棋规算法与纯函数逻辑（已 TDD）
- `src/models/`：数据结构与类型定义
- `src/styles/`：全局与模块化样式
- `legacy/`：旧版对照，仅参考

## 组件拆分与数据流
**布局结构**：棋盘区 + 右侧控制区 + 下方记录区。

组件职责：
- `App.tsx`：整体布局与样式入口
- `BoardCanvas`：棋盘背景、棋子绘制、坐标点击映射、翻转显示
- `ClockPanel`：时钟显示、规则设置、开始/暂停/重置
- `RecordPanel`：当前线路/片段集合切换、棋谱列表、高亮、注释、分支点、下划线
- `ControlPanel`：文件/棋局/播放/镜像/翻转等按钮
- `SetupPanel`：摆棋模式与棋子选择
- `StatusBar`：文件名、修改状态、模式等信息

**数据流**：组件只通过 `useXiangqiStore` 读取状态与触发动作；棋盘点击 → `onBoardCellClick` → 状态更新 → 棋盘/棋谱同步刷新；棋谱点击 → `selectMoveIndex` → 重建局面。

## 功能对齐清单（必须全部实现）
- 走法与合法性校验、棋谱生成
- 当前线路与片段集合切换
- 注释、分支点标记、下划线标记
- 片段保存、分支与回溯
- 播放当前片段与播放全部片段
- 棋盘翻转、棋谱镜像
- 摆棋模式
- 时钟规则（基本/增量/步时）
- 文件新建/打开/保存/另存/复制棋谱

## 文件格式与兼容
- JSON 格式：`{ version, created, modified, games[] }`
- 兼容旧版数组格式（若是数组则视为 games）
- 保存时统一生成版本信息

## 播放与语音策略
- 播放：基于“片段队列 + step 索引 + 定时器”推进
- 语音：先保持旧版行为（若有），后续可接入 Web Speech 或 Tauri 侧能力

## 样式现代化策略（分两步）
1) **对齐旧版结构**：复用 `src/styles/app.css`，保证 class 与布局一致
2) **视觉升级**（第二阶段）：统一色板、层级、间距与按钮状态，适度柔和背景与阴影，保持棋盘聚焦

## 风险与缓解
- **功能遗漏**：以旧版功能清单逐项对照；优先保证功能可用
- **状态迁移不完整**：先集中在 store 完整对齐，再拆分 slice
- **UI 事件漏接**：组件拆分后逐项映射旧版按钮与交互

## 验收标准
- 旧版功能全部可用且行为一致
- 文件读写正常，兼容旧格式
- 走子、棋谱、片段、播放、时钟均稳定
- 视觉结构与旧版一致（允许局部轻微差异）

## 后续实施步骤（概述）
1) 用 React 组件重建旧版布局与事件绑定
2) 连接 `useXiangqiStore` 动作与 UI
3) 校对棋谱/片段/播放/时钟逻辑
4) 修复视觉细节并完成现代化（阶段二）
