# 项目结构与模块说明

本文档说明当前项目的文件结构、模块职责、关键数据流与实现要点，便于后续维护与扩展。

## 1. 目录结构
```
.
├── 中国象棋.html
├── 象棋棋盘.png
├── css
│   └── styles.css
└── js
    ├── state.js
    ├── dom.js
    ├── board.js
    ├── record.js
    ├── clock.js
    ├── game.js
    ├── file.js
    ├── playback.js
    └── init.js
```

## 2. 总体依赖与加载顺序
`中国象棋.html` 中按如下顺序加载脚本（必须保持）：
1) `js/state.js`（全局状态与常量）
2) `js/dom.js`（DOM 引用）
3) `js/board.js`（棋盘与走子）
4) `js/record.js`（棋谱、片段、注释）
5) `js/clock.js`（时钟规则）
6) `js/game.js`（棋局管理）
7) `js/file.js`（文件管理）
8) `js/playback.js`（播放与语音）
9) `js/init.js`（初始化与事件绑定）

原因：各模块使用了全局变量与函数，必须先加载状态与 DOM，再加载依赖这些变量的逻辑模块。

## 3. 模块详细说明

### 3.1 `中国象棋.html`
职责：
- 提供页面结构与交互元素（棋盘、控制面板、按钮、输入框等）。
- 引入 `css/styles.css` 与 `js/*` 脚本。

实现要点：
- 通过大量 `id` 供 JS 绑定事件与更新 UI。
- 页面只保留结构，不再包含内联样式与脚本。

### 3.2 `css/styles.css`
职责：
- 全部样式与布局定义（棋盘尺寸、面板布局、按钮样式、棋谱高亮等）。

实现要点：
- 棋盘背景图使用相对路径：`../象棋棋盘.png`。
- 通过 `class` 控制状态样式（如 `.playing`、`.selected`）。

### 3.3 `js/state.js`
职责：
- 定义全局常量与全局状态。

实现要点：
- 棋盘常量：`BOARD_WIDTH`、`BOARD_HEIGHT`、`ROWS`、`COLS`。
- 棋子与初始布局：`pieceTypes`、`defaultLayout`。
- 运行状态：`currentTurn`、`gameOver`、`currentLine`、`savedFragments` 等。
- 这些变量在各模块直接读取/修改，是当前架构的“状态中心”。

### 3.4 `js/dom.js`
职责：
- 统一获取并保存所有核心 DOM 引用。

实现要点：
- 通过 `document.getElementById` 获取节点，如 `chessGrid`、`recordArea` 等。
- 供其它模块直接使用，避免重复查询。

### 3.5 `js/board.js`
职责：
- 棋盘与棋子的渲染、坐标映射、走法校验与执行。

核心实现：
- 走法校验：`validateMove`，根据棋子类型判断合法性。
- 走子执行：`executeMove`，更新棋盘与棋谱状态。
- 坐标处理：`setPiecePosition` 负责棋盘翻转时的坐标映射。
- 交互入口：`handleBoardClick` 处理点击落子逻辑。
- 辅助：`createPiece`、`getPieceAt`、`removePieceAt`。

与其他模块协作：
- 执行走子后会触发 `renderRecord`、`updateStatusInfo`、`markFileModified`。
- 时钟逻辑通过 `handleClockAfterMove` 调用 `clock.js`。

### 3.6 `js/record.js`
职责：
- 棋谱记录、注释、片段管理、标记功能与棋谱渲染。

核心实现：
- 棋谱渲染：`renderRecord`、`renderCurrentLine`、`renderFragmentsView`。
- 片段逻辑：`branchFromHere` 生成片段与新线路。
- 标记：`markBranchPoint`、`deleteBranchPoint`、`markUnderline`。
- 注释：`addComment`、`saveComment`、`showCommentForMove`。
- 视图模式切换：`switchViewMode`、`updateViewModeButtons`。
- 棋谱镜像：`mirrorRecord`、`createMirroredGame`、`mirrorMoveList`。

与其他模块协作：
- 棋盘回放通过 `replayBoard` / `renderBoardToStep` 使用 `board.js` 的棋子操作函数。
- 片段与注释状态变化会触发 `markFileModified` 与 `updateStatusInfo`。

### 3.7 `js/clock.js`
职责：
- 计时规则与时钟控制。

核心实现：
- 规则切换：`selectRule`、`updateClockSettings`。
- 计时更新：`updateClocks`、`startClock`、`pauseClock`、`resetClock`。
- 步时制与加秒制的时间累加逻辑。

与其他模块协作：
- `board.js` 在每步落子后调用 `handleClockAfterMove` 来切换时钟。

### 3.8 `js/game.js`
职责：
- 棋局级管理（加载、保存、切换、排序、删除、恢复）。

核心实现：
- 当前棋盘状态保存：`getCurrentBoardState`。
- 加载棋局：`loadGame`，初始化棋盘与棋谱。
- 棋局管理：`deleteGame`、`restoreGame`、`renameGame`、`moveGameUp/Down`。
- 新局与摆棋：`newGame`、`startGame`、`toggleSetupMode`。

与其他模块协作：
- 加载棋局后调用 `renderRecord`、`updateClocks`、`updateStatusInfo`。

### 3.9 `js/file.js`
职责：
- 棋谱文件的打开/保存/另存为与状态提示。

核心实现：
- 文件打开：优先 File System Access API，失败降级文件选择器。
- 文件保存：`saveFile`、`saveAsFile`。
- 文件解析：`parseFileContent` 支持新旧格式。
- 变更标记：`markFileModified` 与 `updateFileStatus`。

### 3.10 `js/playback.js`
职责：
- 片段播放与语音朗读。

核心实现：
- 播放控制：`playCurrentFragment`、`playAllFragments`、`stopPlay`。
- 播放节奏：`playNextStep`（片段 2+ 在分支点前快速）。
- 视觉高亮：`highlightPlayStep`。
- 语音朗读：`speakMove`（仅正常速度时朗读）。

### 3.11 `js/init.js`
职责：
- 初始化与事件绑定的唯一入口。

核心实现：
- `init()` 负责调用：
  - `renderSetupPieces()`、`renderDefaultLayout()`
  - `updateClocks()`、`updateClockSettings()`
  - `bindEvents()`、`loadSavedGames()`
  - `updateStatusInfo()`、`updateViewModeButtons()`
  - `updateMarkButtons()`、`updateFileStatus()`、`updatePlayButtons()`
- `bindEvents()` 统一绑定所有按钮与交互事件。

## 4. 关键数据流说明
- 落子流程：`handleBoardClick` → `validateMove` → `executeMove` → 更新棋谱/状态/时钟。
- 文件加载：`openFile` → `parseFileContent` → `loadGame` → 刷新棋盘/棋谱/状态。
- 片段变着：`branchFromHere` → 保存片段 → 新线路重建 → 回放棋盘。
- 播放流程：`playAllFragments` → `playNextStep` → `playStep` → `replayFragmentStep`。

## 5. 维护与扩展建议
- 新增棋盘/走子规则：放入 `js/board.js`。
- 新增棋谱/标记能力：放入 `js/record.js`。
- 新增计时规则：放入 `js/clock.js`。
- 新增文件格式：放入 `js/file.js` 并扩展 `parseFileContent`。
- 新增按钮：在 `中国象棋.html` 添加元素，在 `js/dom.js` 引用，在 `js/init.js` 绑定事件。

如需进一步解耦（如引入 `AppState` 或 ES Modules），可在现有拆分基础上渐进重构。
